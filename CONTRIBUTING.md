# Guía de Contribución

¡Gracias por tu interés en colaborar en este proyecto de pruebas! Para mantener el orden, sigue estos pasos:

## Cómo Empezar
1. Haz un **Fork** de este repositorio.
2. Clona tu fork localmente: `git clone https://github.com`
3. Crea una nueva rama para tus cambios: `git checkout -b mi-rama-de-prueba`

## Reglas para los Commits
- Usa mensajes claros y en tiempo presente (ej: `Fix: Corregir error en login` o `Feat: Agregar sección de contacto`).

## Enviar Cambios
1. Sube tus cambios a tu fork: `git push origin mi-rama-de-prueba`
2. Abre un **Pull Request** hacia la rama principal de este repositorio explicando brevemente tus cambios.
